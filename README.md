# LedgerX Store
E-commerce-oriented static storefront for LedgerX books.

## Included
- E-book and physical-book catalog
- Product detail modal
- Shopping cart with localStorage
- Bundle section
- Responsive mobile design
- Demo checkout placeholder

## Important
The checkout is intentionally a demo. Before accepting real customer payments or delivering paid e-books, connect a suitable payment/order backend and secure digital-file delivery.

## Deploy
Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub Pages repository.
